# Dump photos here 📸

Drop your image files straight into this folder. They show up on the home page collage and
in `/gallery` automatically — no code to edit.

- Formats: `.jpg` `.jpeg` `.png` `.webp` `.avif` `.gif`
- Order is by filename → prefix with `01-`, `02-`, … if you care about the sequence
- Captions are optional, added in `content/site.ts`

Details and tips (resizing, ordering, how it works): [`../../docs/PHOTOS.md`](../../docs/PHOTOS.md)
